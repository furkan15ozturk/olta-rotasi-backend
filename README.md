# OltaRotası Backend

FastAPI + PostgreSQL/PostGIS; Docker Compose ve Nginx kurulum dosyaları.

- API: `backend/app/`
- Test: `cd backend && python -m pytest tests`
- VPS kurulum: `sudo bash deploy/install.sh`
- Ayrıntılar: [backend/README.md](backend/README.md)

Frontend: https://github.com/furkan15ozturk/olta-rotasi-frontend
Mera, çevresel veri, öneri modeli ve Flutter bağlantısı henüz bağlı değildir.
